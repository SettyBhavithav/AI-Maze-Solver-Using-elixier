## 🌟 Overview

**AI Hand Gesture Gaming — Maze Solver** fuses high-speed computer vision hand tracking with concurrent graph pathfinding algorithms implemented in **Elixir**. It enables 100% touchless, gesture-controlled maze navigation using webcam input without a keyboard or mouse.

---

## ✨ Key Features

- 🖐️ **MediaPipe Skeletal Hand Tracking**: Real-time 21-keypoint landmark detection for precise directional gesture steering.
- ⚡ **Concurrent Graph Solvers in Elixir**: Concurrent BFS, DFS, and A* search pathfinding solvers leveraging Erlang/OTP processes.
- 🎮 **Touchless Arcade Gameplay**: Dynamic collision detection and maze navigation.
